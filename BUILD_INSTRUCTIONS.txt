BUILD ENVIRONMENT
Operating System: Windows
Flutter SDK: C:\flutter
LLVM: C:\Program Files\LLVM
vcpkg: C:\vcpkg
Target: Windows x64 Release

BUILD PROCEDURE

1. Install the required RustDesk build dependencies,
   including Flutter, Rust, Visual Studio C++ tools,
   LLVM and vcpkg.

2. Open Windows PowerShell.

3. Navigate to the source-code directory.

4. Run the following commands:

$env:PATH = "C:\flutter\bin;C:\Program Files\LLVM\bin;$env:PATH"
$env:VCPKG_ROOT = "C:\vcpkg"
$env:VCPKG_DEFAULT_TRIPLET = "x64-windows-static"

cd flutter

flutter pub get

flutter build windows --release

5. The Windows executable should be generated at:

flutter\build\windows\x64\runner\Release\rustdesk.exe

NATIVE RUST LIBRARY BUILD

Before building the Flutter Windows application:

1. Open PowerShell in the CPA Remote Support source directory.

2. Configure the build environment:

$env:PATH = "C:\flutter\bin;C:\Program Files\LLVM\bin;$env:PATH"
$env:VCPKG_ROOT = "C:\vcpkg"
$env:VCPKG_DEFAULT_TRIPLET = "x64-windows-static"

3. Build the native Rust library:

cargo build --locked --features flutter --lib --release

4. Confirm the output exists:

target\release\librustdesk.dll

5. Build the Flutter Windows application:

cd flutter
flutter pub get
flutter build windows --release

Note: The required toolchains, dependencies and generated
Flutter-Rust bridge files must be configured correctly.
These steps still require verification using an independent
source-code build.
